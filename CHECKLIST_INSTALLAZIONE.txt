📋 CHECKLIST DI INSTALLAZIONE - MONSTER COUNTRY DJ

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PRIMA DI INIZIARE:

  ☐ Avere Windows 10 o superiore
  ☐ Avere connessione a Internet
  ☐ Avere ~500 MB di spazio libero
  ☐ Avere estratto la cartella ZIP

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INSTALLAZIONE (2 PASSAGGI):

  ☐ PASSO 1: Doppio-click su "START-UNATTENDED.bat"
  
  ☐ PASSO 2: Aspetta 10-15 secondi che il server si avvii
            (Vedrai una finestra nera che si apre)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ACCESSO ALL'APP:

  ☐ Il browser si apre automaticamente a:
    http://localhost:5500/
    
  ☐ Se non si apre, copia e incolla l'indirizzo sopra
    nel browser manualmente

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PRIMO AVVIO (AUTOMATICO):

Durante il primo avvio, il sistema fa automaticamente:

  ☐ Scarica le dipendenze (npm install)
  ☐ Crea il file di configurazione (.env)
  ☐ Crea le cartelle necessarie
  ☐ Sceglie una porta libera (5500, 5501, ecc.)
  ☐ Avvia il server

NOTA: Non devi fare nulla! È tutto automatico.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VERIFICA CHE TUTTO FUNZIONI:

  ☐ Vedi la finestra PowerShell con scritte colorate (bianche/verdi)
  ☐ Leggi "Server pronto" o "HTTP 200"
  ☐ Il browser è aperto e vedi la pagina
  ☐ Non vedi scritte rosse (errori)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FINITO! ✅

Il server è online e pronto all'uso.

Quando hai finito:
  → Doppio-click su "STOP.bat" per spegnere il server

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SE QUALCOSA NON FUNZIONA:

  1. Doppio-click su "DIAGNOSTICA.bat"
  2. Leggi il file "INSTALLA_NUOVO_PC.md" (sezione "PROBLEMI COMUNI")
  3. Se ancora non funziona, contatta il supporto con:
     - Output di DIAGNOSTICA.bat
     - Il messaggio di errore
     - Contenuto di: logs\server-portable.log
